<br/>
Программа для обработки измерений термического анализа.
</p>

# Требования
python 3.11
<br/>
[poetry](https://python-poetry.org/docs/)

# Установка
```r
git clone https://gitflic.ru/project/i-o-yurev/fusion-analysis.git
cd fusion-analysis
poetry install
```

# Запуск
Перед первым запуском выполните команду:
```r
uic.cmd
```

Для запуска выполните команду:
```r
run poetry python fusion_analysis
```

# Сборка
```r
deploy_pyinstaller.cmd
```
После выполнения команды сборка будет расположена в подпапке pyinstaller/dist.
