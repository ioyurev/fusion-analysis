# Инструкции для Fusion Analysis

## Контроль качества и команды разработки

Все команды выполняются из корня `fusion-analysis`:

- Запуск приложения из исходников (со сплэш-экраном): `.\run.cmd` (или `uv run python -m fusion_analysis`)
- Сборка исполняемого дистрибутива PyInstaller: `.\build.cmd`
- Обязательные проверки качества:
  - `uv run ruff check . --fix`
  - `PYTHONUTF8=1 uv run mypy . --pretty`
  - `uv run vulture`
  - `uv run pytest`

## Архитектурные правила

1. **Неизменяемость сырых измерений и формат анализа `.fusa`:** Файлы сырых измерений (`.fus`, `.vtaz`, `.tda`, `.fus-mdt`, `.fus-fmdt`, `.txt`) открываются строго на чтение. Все результаты работы аналитика (сглаженные кривые любых каналов, разрезанные сегменты, сдвиги, цвета, пики, базовые линии и онсеты) сохраняются исключительно в отдельный файл анализа `.fusa`.
2. **Многоканальное сглаживание и дифференцирование в тулбаре:** Инструменты «Сглаживание» (с живым предпросмотром на основном графике и полупрозрачным призрачным исходником) и «Производная» (1-го и 2-го порядка) расположены на верхнем тулбаре главного окна и применимы к любой выделенной кривой (`DTA`, `Temp.`, `EMF`, `Mass`, а также к самим производным).
3. **Модуль видео-оверлея ВТА (`fusion_analysis/video_overlay/`):** Встроен как вторая вкладка главного окна («Видео-оверлей ВТА»), автоматически подхватывает открытое и сглаженное измерение и обеспечивает нативную VFR-синхронизацию кадров и экспорт в `.mp4` и `.xlsx`.
